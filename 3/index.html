Overview

In this project, I explore how a pretrained flow model transforms noise into images, how text conditioning changes the sampling process, and how the same process can be used for image editing and optical illusions.

The central idea is to learn and follow a time-dependent velocity field that moves an image from a noise distribution toward the distribution of natural images. I first compare simple and model-based denoising methods, then use Euler integration for sampling and classifier-free guidance (CFG) for stronger prompt alignment.

1. Visualizing Training and Sampling

Flow matching defines a path between Gaussian noise and a clean image. Training samples a time and teaches the model to predict the velocity along that path; sampling starts from noise and numerically integrates the predicted velocity field toward the clean-image endpoint.

\[x_t=(1-t)\epsilon+t x,\qquad \epsilon\sim\mathcal{N}(0,I),\quad t\in[0,1]\]

Here, \(x\) is the clean image, \(\epsilon\) is Gaussian noise, and \(t=0\) corresponds to pure noise while \(t=1\) corresponds to the clean image. For this linear path, the ground-truth velocity is \(v_t=x-\epsilon\).

1.1 Constructing Noisy Training Inputs

I use the same original image and the same sampled noise tensor for all three time values.

\[x_t=(1-t)\epsilon+t x\]

The higher t is, the less noise appear on the image and the more the image is recognizable.

1.2 Classical Denoising

Gaussian blur provides a non-learned baseline. Since the image contribution in \(x_t\) is scaled by \(t\), I first restore its amplitude, then apply a Gaussian filter:

\[\hat{x}_{\mathrm{blur}}=G_{\sigma}\!\left(\frac{x_t}{t}\right)\]

Noise represents versy high frequency details. Blurring suppresses high frequencies, so it helps to supress the noise of the image, but also blurs it.

Gaussian blur comparison

1.3 One-Step Denoising

The pretrained model predicts velocity rather than noise. A single prediction at the current noisy image can be extrapolated to the clean endpoint:

\[\hat{x}_{1}=x_t+(1-t)v_{\theta}(x_t,t,c)\]

I use the text condition a high quality photo. This one-step estimate assumes the predicted velocity remains constant from the current time to \(t=1\).

1.4 Visualizing Velocity

Because the original image and sampled noise are known, the ground-truth velocity is available for comparison with the model's prediction. The update from time \(t\) to the clean endpoint is the velocity multiplied by \((1-t)\).

\[v_{\mathrm{true}}=x-\epsilon,\qquad \Delta x_{\mathrm{pred}}=(1-t)v_{\theta},\qquad \Delta x_{\mathrm{true}}=(1-t)(x-\epsilon)\]

The per-pixel error is the root-mean-square difference across the RGB channels.

1.5 Iterative Denoising with Euler Sampling

Instead of assuming a constant velocity for the entire path, Euler sampling repeatedly evaluates the velocity at the current state and advances by a small step:

\[x_{t+\Delta t}=x_t+\Delta t\,v_{\theta}(x_t,t,c)\]

2. Conditional Generation and Guidance

Text conditioning gives the model information about the desired image. Classifier-free guidance strengthens the effect of the prompt by combining conditional and unconditional velocity predictions.

2.1 Classifier-Free Guidance (CFG)

For the same image and time, I evaluate the model with the desired text prompt and with an empty prompt, then extrapolate away from the unconditional prediction:

\[v_{\mathrm{CFG}}(x_t,t,c)=v_{\mathrm{uncond}}(x_t,t)+w\left(v_{\mathrm{cond}}(x_t,t,c)-v_{\mathrm{uncond}}(x_t,t)\right)\]

I use Euler step size 0.1 and guidance weight \(w=7\). Same prompt: a high quality photo.

Same seeds with CFG : the results look more realistic than before

3.3 Visual Anagrams

Visual anagrams use two prompts at once. I predict velocity for the current image with one prompt, predict velocity for the image rotated by 180° with another prompt, rotate the second velocity back, and average the two. Each Euler step therefore tries to satisfy both interpretations.

\[v_{\mathrm{ana}}(x_t,t)=\frac{1}{2}\left[v_{\mathrm{CFG}}(x_t,t,c_1)+R\left(v_{\mathrm{CFG}}(R(x_t),t,c_2)\right)\right]\]

Here, \(R\) rotates an image by 180° (flipping both spatial axes), and \(c_1,c_2\) are the two text prompts.

3.4 Hybrid Images

Hybrid images combine the low-frequency content of one prompt's predicted velocity with the high-frequency content of another. The low-pass component is a Gaussian blur; the high-pass component is the original prediction minus its low-pass version.

\[v_{\mathrm{hybrid}}=G_{\sigma}*v_1+\left(v_2-G_{\sigma}*v_2\right)\]

I use a Gaussian kernel of size 265 and standard deviation 16 for 512×512 images, then use this composite velocity for the Euler update.
