Image Mosaicing and Autostitching

Recover homographies, implement inverse warping, and combine photographs into image mosaics.

Methods: Homography, interpolation, blending

01 · Overview

From point correspondences to panoramas

This project explores the geometry behind image mosaicing. Given corresponding points in two photographs, a projective transformation is estimated and used to align, rectify, and blend the images.

The implementation includes a least-squares homography solver, custom nearest-neighbor and bilinear interpolation, alpha-based feathering, and cylindrical projection.

02 · A.2

Recovering homographies

A homography maps points between two views using a $3 \times 3$ matrix with eight degrees of freedom:

$\mathbf{p'} \sim H\mathbf{p}$

For each pair of corresponding points, the code builds a linear system $Ah=b$ and solves for the eight unknown entries of $H$ with least squares. The final element is fixed to 1.

03 · A.3

Warping and rectification

Images are transformed with inverse warping so every output pixel samples from the input image. I implemented both nearest-neighbor sampling and bilinear interpolation from scratch.

In those examples, objects that are rectangular in real life don't appear exactly rectangular on the images. Recovering homographies and applying warping allows us to output the real shape of the objects.

04 · A.4

Blending image mosaics

For each image pair, I first compute the homography matrix using corresponding points from both images. Then, I use inverse warping to align the right image with the left image, mapping each output pixel back to its corresponding source location, allocating a canvas large enough to accommodate the transformed image. If the homography produces negative coordinates, I compute offsets to shift both images into a shared coordinate system without cropping. Before warping, I compute an alpha channel using ndimage.distance_transform_edt, assigning larger weights to pixels farther from the image boundaries and smaller weights near the edges. Finally, I stitch the aligned images using alpha-weighted averaging in overlapping regions. This feathering approach creates smoother transitions and reduces visible seams between the photographs.

All the following images are warped using Bilinear Interpolation.

Part B · Feature Matching for Autostitching

Automatic mosaics

In Part A, I selected point correspondences manually. In Part B, I automate correspondence selection using Harris corners, adaptive non-maximal suppression (ANMS), and small image-patch descriptors. RANSAC is then used to estimate a homography while rejecting incorrect feature matches. I reuse the warping and blending pipeline from Part A.

B.1

Harris corners and ANMS

Corners, which will become features, are detected using corner_harris from skimage. As a baseline, I select the 250 corners with the largest Harris responses. Strong responses can cluster around the same regions, which makes only using the strongest corners not ideal if regions of overlap between the images are not covered.

ANMS instead ranks corners by their suppression radius: the distance to the nearest corner with a sufficiently stronger response. With a robustness coefficient of 0.9, the comparison is against corners satisfying response(current) < 0.9 × response(other). Selecting 250 corners with the largest suppresion radiuses makes it so that there is a more even distribution of features across the image.

B.2

Feature descriptor extraction

For each selected corner, I extract a 40×40 grayscale patch, blur it with a 5×5 Gaussian kernel, and resize it to 8×8. This captures a larger neighborhood, reduces the noise and makes future feature matching more efficient. The patches are also normalized, by substracting its mean and dividing by its standard deviation.

B.3

Matching features

I compare normalized descriptors using the sum of squared differences (SSD). For each descriptor in the first image, I find its nearest and second-nearest neighbors in the second image. I apply Lowe’s ratio test separately to each query descriptor: I divide its nearest-neighbor SSD by its own second-nearest-neighbor SSD and retain ratios below 0.6. If a ratio is close to 0, it means that the first match is likely to be right, whereas if the two nearest neighbors have a similar score (ratio close to 1), then we are not so sure about which is the real match, so we discard it.

I run matching in both directions and keep mutual matches: a feature in the first image must select a feature in the second image that also selects it back.

B.4

Robust homographies and automatic mosaics

Because some visually similar patches can have different physical locations, I implement RANSAC to reject incorrect matches. Four mutual correspondences are sampled and used to estimate a homography mapping the second image into the first, like in Part A. All other matched features computed from the previous parts are then projected, and their Euclidian distance from the corresponding points in the first image are computed. Matches with errors under 5 pixels are counted as inliers.

After 10,000 iterations, I refit the homography using all inliers from the model that accounted the highest number of inliers. Before estimating each homogrpahy, I center each point set and scale its mean distance from the origin to √2 to improve numerical stability.

Finally, I warp with bilinear interpolation and blend using the alpha masks from Part A. Below are saved automatic and manually aligned results.

B.5 · Bells & whistles

Panorama recognition from unordered images

For the Bells and Whistles, I stitch mosaics from unordered sets of images. I detect corners and extract descriptors for every image, then match all image pairs in both directions. I build a graph with an image at each node and weight each edge by the smaller of the two directional match counts. This allows to see which images should be stitched together. If a pair of images has a very low number of matched features, the two images probably shouldn't be stitched together.

A maximum spanning tree selects strong connections between images. I choose a node with the highest tree degree as the initial reference, to reduce stretching and distortion. The first pair is aligned with RANSAC and blended. For each subsequent image, I detect features again on the growing mosaic, match the new image to it, estimate another homography, and blend the image with the current mosaic.

This allows the input list of images to be unordered.
